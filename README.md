# CoatingOS for Mac

Signed and notarized builds of the CoatingOS Mac app, and the update feed installed copies read to keep themselves up to date. The app's source code isn't kept here.

**Download:** [coatingos.com/download/mac](https://coatingos.com/download/mac) (macOS 13 or later, Apple silicon or Intel). Open the download and drag CoatingOS into Applications.

Signed in to CoatingOS in a browser on a Mac? Settings → My Account → Mac app has the same link.
